# Category Lenses

Use this file when the inquiry is in an unfamiliar category and you need a better first-pass breakdown before drafting client questions.

The purpose is not to become an expert. The purpose is to avoid generic questioning and focus on the variables that usually decide sourcing feasibility.

## How to use

1. Identify the closest commercial category
2. Pull only the relevant lens below
3. Use it to decide:
   - what this product probably is
   - what usually drives price and MOQ
   - what questions matter first
4. Return to the main skill output format

## 1. Standard commodity / off-the-shelf product

Typical examples:
- kitchen tools
- simple home goods
- basic accessories
- generic hardware

Usually care about:
- dimensions and material
- finish / color / packaging
- logo or no logo
- quantity tiers
- target price band

Push forward questions about:
- exact size / material
- packaging and branding
- quantity by SKU
- reference image or link
- target market if labeling or compliance may matter

## 2. Appearance-custom product / gift / promo item

Typical examples:
- gift boxes
- branded drinkware
- plush gifts without electronics
- corporate promo items

Usually care about:
- design reference
- printing / embroidery / logo method
- packaging quality
- quantity tiers
- delivery deadline

Push forward questions about:
- artwork or visual reference
- branding method
- expected quality level
- event date or ship deadline
- whether existing molds / shapes are acceptable

## 3. Apparel / textile / bag

Usually care about:
- fabric composition and weight
- construction details
- size range
- trims and labels
- colorways
- sampling and grading
- quantity per style / color / size

Push forward questions about:
- tech pack or reference sample
- fabric preference and feel
- target price per piece
- quantity breakdown by size and color
- labeling and packaging needs
- test order vs production order

## 4. Electronics / smart device / AI hardware

Usually care about:
- function definition
- existing solution vs custom development
- chip / module / connectivity
- battery / power
- enclosure / industrial design
- app or software dependency
- certification needs
- MOQ and tooling

Push forward questions about:
- core functions and must-have features
- existing reference products
- stock solution vs custom development preference
- target market and certification
- battery / charging / connectivity requirements
- sample timeline and first order volume

## 5. Machinery / industrial equipment

Usually care about:
- application scenario
- production capacity
- operating environment
- voltage / standards
- installation and training
- after-sales support
- spare parts and maintenance
- shipping and commissioning complexity

Push forward questions about:
- exact machine type and use case
- required capacity or output
- target country and electrical standard
- automation level
- budget range
- whether on-site installation / training is needed
- consumables / spare parts expectations

## 6. Building material / construction product

Usually care about:
- exact product family
- material grade
- standards / certification
- project volume
- finish / durability
- destination market requirements
- packing and shipping mode

Push forward questions about:
- specific product name and use in project
- drawings / dimensions / specs
- required standard or certification
- project quantity and repeat potential
- destination market
- price target and delivery schedule

## 7. Beauty / personal care / food-contact / regulated product

Usually care about:
- formulation or material safety
- regulatory compliance
- packaging compatibility
- registration / test requirements
- labeling
- production license status

Push forward questions about:
- target market and channel
- regulatory requirement already known by buyer
- white-label vs custom formula / structure
- ingredient or material restrictions
- packaging format
- trial quantity vs commercial quantity

## Fast heuristics

### If the buyer wants low MOQ + deep customization
Assume a feasibility conflict until clarified.

### If the buyer gives no target market
Move market and compliance questions up.

### If the buyer only asks for the cheapest option
You still need to clarify minimum usable quality, not just price.

### If the buyer shares a competitor link
Use it as a commercial anchor, but do not assume the same specs or cost structure.

### If the buyer sounds early-stage
Bias toward narrowing scope and defining the first test order, not solving the full future roadmap.
